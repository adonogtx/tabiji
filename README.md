# Tabiji 旅路

![Java](https://img.shields.io/badge/Java-21-orange)
![Spring Boot](https://img.shields.io/badge/Spring%20Boot-4.1.1-brightgreen)

A seat reservation backend inspired by Japan's Shinkansen, using fictional stations and trips. Built with Java and Spring Boot.

*旅路 (たびじ, tabiji): a journey, or the route of a journey.*

## Status

Work in progress.

## Requirements

- Java 21
- No Maven installation needed, the project uses the Maven Wrapper

## Running the application

```
./mvnw spring-boot:run
```

The application starts on port 8080. There are no endpoints yet.

## Running the tests

```
./mvnw test
```

## Building

```
./mvnw package
```
